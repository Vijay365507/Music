About TuneWave

TuneWave is a practice music-streaming website built to learn front-end web development — HTML, CSS, and JavaScript — through a real-world style project.

It includes a song browser, search and category filters, a mini music player, liked songs, premium plans, checkout and payment flow, and user profiles — all powered by the browser's localStorage, with no backend server required.

This project is for learning purposes only and is not a commercial music service.
